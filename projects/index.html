QiitaExplore is a research console that sits in front of Qiita's database of thousands of public microbiome studies. Built during my time as a researcher at Knight Lab, UC San Diego, it replaces manual, one-study-at-a-time browsing with natural-language search, an agentic chat assistant, and a workspace for curating and merging study data.

Highlights

  • Shipped an open source full-stack web app delivering NLP search, metadata exploration, and collaborative workflows — now used by 15+ researchers across 600+ studies.
  • Cut study discovery time from 15 minutes to 3 minutes by writing multi-table SQL joins and granular sample-metadata queries, optimizing PostgreSQL queries, lazy-loading large tables, and caching repeated lookups.
  • Designed a reusable, model-agnostic agent orchestration framework connecting 7 LLM backends with 4 research tools via JSON-schema tool arguments, with automatic fallback mechanisms for reliable multi-step execution.

SimWorld is a large-scale simulation framework for training embodied agents in physically and socially realistic environments, built during my time as an AI Research Intern at Q-Lab, UC San Diego. The work was accepted as a Spotlight Presentation at NeurIPS 2025.

Highlights

  • Built a scalable multi-agent simulation system supporting 100+ concurrent interactions by integrating neural networks with Unreal Engine 3D visualization environments, and designing software components for distributed and parallel simulation workloads.
  • Automated large-scale environment generation by integrating UnrealCV with Shap-E to generate 3D assets and environments, developing 200+ validated social-interaction animations and reducing manual setup.
  • Trained context-aware autonomous agents by combining reinforcement learning with chain-of-thought reasoning, improving their ability to interpret natural language prompts and respond to environmental cues.

At WeInvest, I worked as a Software Engineering Intern building the systems behind a quantitative trading research platform — replacing manual backtesting and manual portfolio-construction inputs with autonomous, self-directing pipelines.

Highlights

  • Built a Python financial research platform orchestrating 44,000+ backtests across 78 signal-asset combinations through a nightly ETL pipeline scheduled with cron.
  • Reduced model discovery time from 3 days to 6 hours by engineering an 8-phase statistical validation pipeline with hypothesis testing and adaptive sampling, enforced through automated integration tests.
  • Built an LLM-driven autoresearch loop that generates search boundaries to maximize the Sharpe ratio across automated backtest experiments, with run logs recording the model version for every run.
  • Engineered a KDTree-backed exploration-exploitation sampler combining Latin Hypercube Search with dead-zone enforcement and winner-region local sampling.
  • Refactored a 37,000-line Python trading codebase to eliminate manual analyst inputs to a Black-Litterman / MVO optimizer across an 80–100 ETF universe.

Highlights
